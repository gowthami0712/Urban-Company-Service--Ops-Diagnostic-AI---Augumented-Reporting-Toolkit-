# Urban Company Data Analytics Project

## Project Overview
This project focuses on analyzing Urban Company data to understand revenue, booking trends, service categories, and business performance.

## Objectives
- Analyze total revenue and booking count.
- Identify popular service categories.
- Understand revenue generated by different services.
- Create KPI cards, pivot tables, charts, and dashboards.
- Present insights to support business decision-making.

## Tools Used
- Microsoft Excel
- Tableau

## Project Workflow
1. Data collection and cleaning.
2. Data analysis using Excel.
3. Creation of pivot tables and KPI metrics.
4. Visualization using charts.
5. Dashboard creation in Tableau.
6. Analysis of key business insights.

## Key Insights
The analysis helps identify revenue trends, booking patterns, and service categories that contribute to business performance.

## Conclusion
This project demonstrates how Excel and Tableau can be used to analyze Urban Company data and present meaningful business insights through interactive dashboards.
